# Desafio – Analisador de Valores

Crie a função:

```js
function analisarValor(valor) { ... }
```

Ela deve:
1. Exibir o valor.
2. Mostrar seu tipo (typeof).
3. Informar se é primitivo ou referência.
4. Sugerir uma conversão útil:
   - number → string
   - string → number ou boolean
   - array → length
   - boolean → number

Extra:  
Crie 5 botões no HTML para testar diferentes valores.
